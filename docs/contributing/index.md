# Contributing

*This section is for people working on LLMHub's code.*

LLMHub is developed in the open on
[GitHub](https://github.com/Center-for-AI-Innovation/LLMHub). The developer
docs live in the repository, next to the code:

| For | Read |
|---|---|
| Setting up a development environment, the repository layout, and day-to-day commands | The [README](https://github.com/Center-for-AI-Innovation/LLMHub/blob/main/README.md) |
| How to open a pull request: CI checks, the changelog rule, tests, and these docs | [CONTRIBUTING.md](https://github.com/Center-for-AI-Innovation/LLMHub/blob/main/CONTRIBUTING.md) |
| The backend on its own | [backend/README.md](https://github.com/Center-for-AI-Innovation/LLMHub/blob/main/backend/README.md) |
| Frontend conventions, including the Illinois design system | [frontend/AGENTS.md](https://github.com/Center-for-AI-Innovation/LLMHub/blob/main/frontend/AGENTS.md) and [the design system](https://github.com/Center-for-AI-Innovation/LLMHub/blob/main/frontend/docs/04-design-system.md) |

To report a bug or ask for a feature, open an
[issue](https://github.com/Center-for-AI-Innovation/LLMHub/issues).

For how the pieces fit together, see [How It Works](../how-it-works/index.md).
